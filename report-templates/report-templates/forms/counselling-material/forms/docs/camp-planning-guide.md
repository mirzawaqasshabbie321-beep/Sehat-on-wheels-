# Camp Planning Guide - How to Run a Sehat on Wheels Camp

### 2 Weeks Before Camp
- [ ] Select village with Union Council / Masjid / School permission
- [ ] Announce in Masjid, School, WhatsApp groups
- [ ] Arrange van, portable ultrasound, portable X-Ray, generator
- [ ] Print 200 registration forms, reports, referral slips
- [ ] Confirm team: Sonologist, X-Ray Tech, Counsellor, Driver + Helper

### Camp Day Timeline
- 7:00 AM - Leave Lahore, load equipment
- 9:00 AM - Setup in School / BHU, registration starts
- 9:30 AM - Triage - RED patients first
- 10:00 AM - 4:00 PM - Scans + Counselling
- 4:00 PM - Pack up, count patients, referral follow-up list
- 5:00 PM - Return

### Budget - Per Camp (150 Patients)
- Van + Fuel: Rs. 10,000
- Team Food + Allowance: Rs. 8,000
- Printing + Stationery: Rs. 3,000
- Generator Fuel + Misc: Rs. 4,000
- Total: Rs. 25,000 - 35,000

### Equipment Checklist
- Portable Ultrasound + Gel + Tissue
- Portable X-Ray + Cassettes / Detector + Lead Apron
- Generator + Extension + UPS
- BP Machine, Sugar Machine, Gloves, Sanitizer
- Laptop / Printer for reports

### Success Measure
- Total patients seen
- How many RED referrals sent?
- How many pregnant women got first scan?
- Did every patient get counselling in Urdu?
